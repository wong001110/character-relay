# Intelligence & Social Product Completion

This phase closes the product gaps left after Stabilization vNext without changing the core Character roleplay provider contract.

## Product authority

- Deployment Edit controls runtime policy and permissions.
- Intelligence observes current Server / Character runtime state.
- Conversation routing authority is Burst → Segment → Semantic Thread, not the legacy single-current-Topic projection.
- Social authority is directional Relationship State v2 + evidence-grounded Person Impression. Legacy aggregate relationship learned state remains compatibility evidence only.
- Canonical Relationship belongs to Character Card authoring and does not silently overwrite existing Server-lived state.

## Completed surfaces

- Intelligence → Social unifies Bot→User and Bot→Bot Relationship State with Familiarity / Affinity / Trust / Comfort, Person Impression, and recent evidence.
- Intelligence → Social → Character Card Relationships provides directional canonical Relationship Sheet authoring and AI-drafted Starting Dynamics for both directions.
- Intelligence → Participation exposes durable admission state plus persisted Segment Reply Planner target evidence.
- Intelligence → Conversation now reads a Server Profile-scoped Conversation Structure endpoint instead of borrowing an arbitrary Deployment as API authority.
- Intelligence → Discovery owns sessions, perception, decisions, share review, and manual browse observability.
- Deployment Edit retains settings-only Discovery policy.
- The embedded legacy Smart Participation Studio is removed from the active product surface; compatibility persistence remains for existing runtime cooldown fallback.
- Legacy Topic / Social projections remain available only inside Character Data as explicit migration/audit compatibility evidence.

## Evidence boundaries

- Derived Person Impression summaries are generated only from stored Relationship State and persisted relationship evidence when no explicitly stored impression exists.
- Historical Reply Planner decisions are not invented; the observatory starts persisting vNext decisions from this release forward.
- Existing legacy Topic, relationship, and Smart Participation persistence is retained for compatibility and migration safety.
